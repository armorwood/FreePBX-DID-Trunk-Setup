# FreePBX-DID-Trunk-Setup
Simple guide for setting up DID trunks for FreePBX, and the possible complications when setting up.

**NOTE: I AM NOT A PROFESSIONAL; THIS IS MAINLY FOR EDUCATIONAL AND DOCUMENTARY PURPOSES. This tutorial is mainly for home lab PBXs**

**What is a DID, and where can I purchase one?* A DID (Direct Inward Dialing) number lets you directly connect your PBX, such as your IVR menu, to a real phone number that others can call. DIDs are very cheap as well, you can buy a local area code number for around 5-10usd with credits for outbound and inbound calls.
